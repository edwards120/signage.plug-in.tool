# Security and Project Data

SignSpec Studio is intended to handle field photographs, addresses, client information, estimates, specifications, and approval records. That information can be commercially sensitive even when it is not legally classified as confidential.

## Do not commit

- API keys, passwords, tokens, or private URLs
- Client addresses or contact information used for testing
- Unreleased estimates, bids, or vendor pricing
- Survey photographs from real client sites
- Permit documents containing personal or restricted information
- Local databases or uploaded project files

Use fabricated demonstration data in this public repository.

## Rules and compliance limitations

Calculations in this repository are decision-support tools. They do not constitute:

- Stamped engineering
- Permit approval
- Legal advice
- Final accessibility certification
- A fabrication release

Any rule profile must identify its source, jurisdiction, edition or date, assumptions, and review status before it is used in a real project.

## Reporting a security concern

Do not publish credentials or sensitive client details in a public issue. Contact New Era Designs privately with the repository name, affected file or feature, and enough information to reproduce the concern without exposing additional private data.
